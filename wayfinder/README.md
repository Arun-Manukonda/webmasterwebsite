# Wayfinder: AI Learning Trails (TSA Webmaster starter #2)

Plain HTML, CSS, and JavaScript. There are no frameworks and no build step. Open `index.html` in a browser to run it.

## Files
- `index.html`: home page
- `trail-think.html`, `trail-use.html`, `trail-right.html`: the three trails
- `passport.html`: ranks, streak, trail logbook, stamps, and journal
- `sources.html`: the required reference page (the [n] citations link here)
- `css/style.css`: all styles
- `js/progress.js`: game engine (XP, ranks, stamps, streak, saving)
- `js/content.js`: quiz questions and activity data. Edit questions here.
- `js/trail.js`: waypoints, quizzes, and the three challenges
- `js/passport.js`: passport rendering

## Before you submit
1. Put your two PDFs in `docs/` using these exact names:
   `student-copyright-checklist.pdf` and `resources-and-ai-reflection.pdf`.
2. Replace `[0000-0]` (Chapter ID) in every page footer, and fill in the
   `[your host]` and `[your editor]` placeholders on sources.html.
3. Click every reference link to confirm it works. Add or replace sources
   with the ones your team actually used.
4. Rewrite the content in your own words and add your own research. Judges
   score originality, and the interview tests what you know.
5. Record your use of AI in the Resources and AI Reflection form.
6. Host it somewhere that is always online, such as GitHub Pages or Netlify.
   Then test it in Chrome, Edge, Firefox, and on a phone.
